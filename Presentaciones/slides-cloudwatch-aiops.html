02 · Herramientas

¿Y Grafana? Azure vs AWS

En Azure usamos Managed Grafana. En AWS existe Amazon Managed Grafana, pero CloudWatch ya trae todo lo necesario.

NecesidadAzureAWS · lo que usamos
Métricas y logsAzure Monitor + Log AnalyticsCloudWatch Metrics + Logs
DashboardAzure Managed GrafanaCloudWatch Dashboards
ConsultasKQLCloudWatch Logs Insights
Anomalías (ML)KQL series_decompose_anomaliesANOMALY_DETECTION_BAND
AlertasAlertas con umbral dinámico + Action GroupAlarmas + SNS (email)
!

Amazon Managed Grafana exige IAM Identity Center, cobra por usuario y muchas organizaciones lo bloquean con una SCP. CloudWatch funciona desde el primer minuto y cuesta centavos.

04 · Dashboard

Logs Insights: preguntas a los logs

Cada invocación deja una línea REPORT. Logs Insights la convierte en campos que se pueden consultar, como SQL sobre los logs.

REPORT RequestId: 42a7… Duration: 217 ms Billed: 218 ms Memory Size: 2048 MB Max Memory Used: 254 MB Init Duration: 4635 ms

¿Cuánta memoria uso?

filter @type = "REPORT"
| stats max(@maxMemoryUsed/1000000) as MemoriaMB,
        max(@memorySize/1000000)    as LimiteMB
  by bin(5m)

Lambda mide en múltiplos de 1000, no de 1024.

¿Cuántos cold starts hubo?

filter @type = "REPORT"
   and ispresent(@initDuration)
| fields @timestamp,
         round(@initDuration) as InitMs
| sort @timestamp desc

Solo los arranques en frío traen @initDuration.

06 · AIOps

Detección de anomalías: el umbral lo aprende el ML

Un umbral fijo ("duración > 500 ms") no sirve si lo normal cambia con la hora. El modelo aprende una banda de normalidad y avisa cuando la métrica se sale.

En código: ANOMALY_DETECTION_BAND(m1, 2). El 2 es el ancho de la banda, en desviaciones estándar.

Ojo: el modelo arranca en PENDING_TRAINING y necesita historial. Créalo con anticipación y genera tráfico normal.
