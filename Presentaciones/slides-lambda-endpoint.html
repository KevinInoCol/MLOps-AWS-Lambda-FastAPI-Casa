02 · Precaución

La Function URL es pública

Con --auth-type NONE cualquiera que tenga la URL puede invocarla, y cada invocación se cobra en tu cuenta.

En clase

Está bien usar NONE para probar rápido desde el navegador y con curl.

No compartas la URL fuera del aula.

En producción

--auth-type AWS_IAM (requests firmadas) o un API Gateway con API keys, throttling y dominio propio.

!

Al terminar la clase, borra todo: Function URL, función, repositorio de ECR y rol IAM (Paso 9 de la skill /aws-lambda-fastapi-deploy).

03 · Dimensionar

No eliges una máquina: eliges memoria

No hay tipo de instancia ni manifiesto. La configuración vive en la propia función. No hay GPU en Lambda.

03 · Dimensionar

Más memoria = más CPU

AWS asigna CPU proporcional a la memoria. Por eso subir memoria a veces sale más barato: la función termina antes y pagas menos milisegundos.

128 MBfracción de vCPU
1769 MB= 1 vCPU completa
2048 MB~1.2 vCPU · esta API
5308 MB~3 vCPU
10 240 MB6 vCPU · máximo
→

Regla práctica: con pandas + scikit-learn, por debajo de ~1 GB el cold start se vuelve lento. Empieza en 2048 MB y ajusta mirando los logs.

03 · Dimensionar

¿Cómo sé cuánto necesito? Mira los logs

Cada invocación deja una línea REPORT en CloudWatch: aws logs tail /aws/lambda/$FUNCTION_NAME

REPORT RequestId: 42a7…  Duration: 160 ms  Billed Duration: 161 ms
Memory Size: 2048 MB  Max Memory Used: 410 MB  Init Duration: 4500 ms
  • MAX MEMORY USEDMuy por debajo del Memory Size → puedes bajar memoria (pero recuerda: menos memoria = menos CPU).
  • CERCA DEL LÍMITESube la memoria antes de que la función muera con signal: killed.
  • INIT DURATION ALTOEs el cold start. Sube memoria o usa concurrencia aprovisionada si importa la latencia.

Cuando algo sale mal: el código HTTP lo dice

El backend responde un código + detail; el frontend lo traduce para el usuario.

CódigoQué pasóQué hace el frontend
200Predicción correctaMuestra métricas, tabla y botón de descarga
400El archivo no es un CSV legible"El archivo debe ser un CSV"
422Faltan columnas que el modelo necesitaLista las columnas faltantes
403Faltan los permisos públicos de la URL"Error 403" → revisar el Paso 6 del despliegue
500Falló algo dentro del backendMensaje genérico · el detalle está en CloudWatch Logs
timeoutNo respondió en 90 s"Reintenta": suele ser el cold start
!

Caso real en clase: subir un CSV de House Sales in King County (bedrooms, zipcode, lat…) devuelve 422. El modelo se entrenó con House Prices de Kaggle (Ames): un modelo solo predice con las variables con las que se entrenó.

Resumen

Para llevarse

  • 01Desplegar en Lambda con Function URL = un endpoint HTTPS con todas las rutas de tu FastAPI.
  • 02Es serverless: escala a cero y cobra por uso. SageMaker cobra por hora aunque nadie lo use.
  • 03No hay manifiesto ni tipo de instancia: eliges memoria y la CPU viene con ella.
  • 04Dimensiona con datos: Max Memory Used e Init Duration en los logs.
  • 05El frontend solo conoce la URL y el contrato (ruta, campo file, CSV). React además necesita CORS.
  • 06La URL es pública: bórrala al terminar.
